# 创作者 Agent 技能包 / Creator Agent Skills

一套给 AI 助手用的技能包，复刻我自己每天在用的创作者工作流：看热点、评选题、改稿子。每个技能独立可用，放在 `skills/<名字>/SKILL.md`，按 Agent Skills 的通用格式写（`name` + `description` + 正文）。

> 内容只写方法与判断标准，不含我的私人选题数据、账号信息、密钥或令牌。

## 技能一览

| 技能 | 解决什么 | 来源 |
| --- | --- | --- |
| [hot-briefing](skills/hot-briefing/SKILL.md) | 每天从公开热榜里筛出值得做的选题 | 我的每日晨间简报（2026-11-14 起每天 08:07 运行） |
| [topic-evaluation](skills/topic-evaluation/SKILL.md) | 判断一个选题值不值得做、从哪个角度做 | 我的选题流程：灵感 → 脚本 → 拍摄 → 剪辑 → 待发布 → 已发布 |
| [de-ai-writing](skills/de-ai-writing/SKILL.md) | 把 AI 味重的改稿改回自然的人话 | 我的改稿习惯：立场与内容不动，只拆公式化节奏 |
| [finance-explainer](skills/finance-explainer/SKILL.md) | 把财经、地缘、汽车热点做成 75 秒竖屏解读短片 | 借鉴 wallstreet-explainer 的镜头表思路（MIT），按我的平台与语气重写：事实关、一表两出、证据上墙、出处随片发布 |

## 我的内容线

三个方向，其他的一律不进简报、不进选题库：

- 两性情感
- 地缘政治、历史
- 汽车话题

目标读者：学生、年轻创业者。

## 原则

- 只写自己跑通过的方法；没验证的标注「未核实」。
- 排名、热度只写核对到的，核对不到就标「未核实」并附来源链接，不编数字。
- 不放任何密钥、令牌、个人隐私信息；不放未发表的私人选题与原稿全文。
