# 财经地缘解读短片

主形态：9:16 竖屏，约 75 秒，抖音、微信视频号、快手、小红书通用。语气冷峻、克制、讲事实，不煽动、不站队表演。

## 开工前先过事实关

1. **核心数字有出处吗？** 片中出现的每个金额、涨幅、时间、名次，都要能指到公开来源（官方通报、公司公告、原始榜单、当事人原发声）。指不到的，删掉或在稿子里明说「未核实」。
2. **是几手消息？** 只有自媒体转述、没有原始出处的，不做主线，只能当背景一句带过。
3. **口径会不会过期？** 涉及政策、裁定、战况的，先确认是不是最新口径，旧闻不新炒。

过不了这三关，退回选题评估，不硬做。

## 一份镜头表，两种出法

先写镜头表，再谈画面。镜头表是全片唯一的骨架（模板见 `templates/shot-list.md`），每行四列：时间段、口播句、画面、屏上文字。

- **真人口播版**：人是底。讲观点时人占主画面；讲证据时人缩到角落小窗，证据截图占满屏。
- **无人出镜版**：同一张镜头表，人的位置换成当事人抠图或关键物件图，口播换成配音。

两种版本共用一份稿和一张表，不为竖屏重写一遍。

## 稿子结构（75 秒，约 330 字）

1. **前 3 秒给反差或给数字**：一句能让人停下来的话——一个大数字、一个反常现象、或一句当事人的原话。不用「大家好」、不用设问开场。
2. **中间算账**：把事件拆成钱和利益的流动——谁出钱、谁得利、谁买单。数字上屏要演出来：大字、对比条、简单柱图，不念表格。
3. **结尾落一句判断**：这件事对普通人（学生、年轻创业者）意味着什么。一句就够，不升华、不喊口号。

写稿时同步去 AI 味：拆掉整齐的排比和每段末尾的金句，节奏回到自然说话的样子（见 de-ai-writing 技能）。

## 画面规则

- **证据上墙**：新闻截图、公告原文、榜单页面直接上屏，关键句刷色标出，观众能自己读到出处，不靠口播转述。
- **一个强调色管全片**：从主画面里取一个颜色，全片的大字、标注、图表都用它，不多色混用。
- **数字要动**：金额和涨幅用大字跳出来，涨跌用柱子或箭头演，不用静态表格糊屏。
- **素材只用评论和解读所需的量**：新闻画面、截图只截关键部分，不整段搬运别人的成片。

## 素材与出处

- 每条片建一份出处清单（模板见 `templates/credits.md`）：素材名、来源链接、用在哪个镜头。
- 出处清单随片发布：写进视频简介或置顶评论，观众能顺着查回去。
- 字体、音乐用可商用或已授权的；来历不明的素材不用。

## 出片检查单

- [ ] 每个数字都能在出处清单里找到来源
- [ ] 没有把「未核实」的内容说成事实
- [ ] 前 3 秒不是自我介绍和设问
- [ ] 全片只有一个强调色
- [ ] 出处清单已随片发布
- [ ] 标题和封面没有夸大稿中没有的结论

## 流水线位置

选题评估通过后进入本技能，产出后按创作流水线推进：

脚本 → 拍摄 → 剪辑 → 待发布 → 已发布

卡住时写清卡在哪一步：缺核实、缺素材，还是角度没想透。
