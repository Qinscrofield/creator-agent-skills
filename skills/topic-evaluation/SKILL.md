# 选题评估

## 先过三道筛

1. **线内吗？** 只做三条内容线：两性情感、地缘政治与历史、汽车话题。线外的再热也不接。
2. **核实得了么？** 核心事实有没有公开可查的来源（官方通报、当事人原发声、原始榜单链接）。只有二手转述、查不到出处的，先放着，不硬写。
3. **角度是新的么？** 别人已经讲烂的角度不重复。换一个能落地的切口：算一笔账、对照读者自己的处境、从一个具体场景讲起。

## 再看合不合读者

目标读者是学生和年轻创业者。能讲出「对他们意味着什么」的选题优先；纯猎奇、纯情绪发泄的往后排。

## 敏感题材的底线

涉及真实当事人的婚育、纠纷、事故类选题：不消费当事人，不拿别人的遭遇当情绪燃料。动笔前先确认事实口径，没有官方口径就不展开细节。

## 流水线位置

选题一旦通过评估就进入创作流水线，按这个顺序推进，状态随时可查：

灵感 → 脚本 → 拍摄 → 剪辑 → 待发布 → 已发布

每一步只往前走，不跳步；卡住的那一步要写清楚卡在哪里（缺素材、缺核实、还是角度没想透），而不是把选题晾在原地。
